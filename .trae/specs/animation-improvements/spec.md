# DragonBones Pro Modern Editor - 动画播放改进

## 概述
- **摘要**：改进DragonBones Pro Modern Editor的动画播放功能，包括切换动画时保持播放状态，以及添加编辑模式和动画模式的切换按钮。
- **目的**：提高动画编辑和预览的效率，防止在播放动画时保存数据引起数据混乱。
- **目标用户**：游戏开发者、动画设计师、美术人员。

## 背景
当前编辑器在切换动画时会自动停止播放并重置到第一帧，这使得用户在比较不同动画时需要手动重新开始播放，影响工作效率。此外，当动画正在播放时进行编辑可能会导致数据混乱，需要一个机制来防止这种情况。

## 功能需求

### 1. 动画切换时保持播放状态
- **FR-1.1**：当用户从动画下拉菜单选择不同动画时，保持当前的播放状态（播放/暂停）
- **FR-1.2**：切换动画后，从第一帧开始播放（如果当前是播放状态）

### 2. 编辑模式和动画模式切换
- **FR-2.1**：添加一个模式切换按钮，在编辑模式和动画模式之间切换
- **FR-2.2**：在动画模式下，允许编辑关键帧
- **FR-2.3**：在编辑模式下，动画自动暂停并恢复到初始状态
- **FR-2.4**：添加录制按钮，自动保存用户修改的关键帧
- **FR-2.5**：添加设置按钮，在用户调整骨骼参数后主动保存关键帧

## 非功能需求
- **NFR-1**：模式切换操作应该响应迅速，不影响用户体验
- **NFR-2**：模式状态应该在UI中清晰可见
- **NFR-3**：功能实现应该保持代码的可维护性和可读性

## 约束
- **技术**：基于现有的React + TypeScript + PIXI.js技术栈
- **依赖**：不引入新的外部依赖

## 接受标准

### AC-1: 动画切换保持播放状态
- **Given**：用户正在播放一个动画
- **When**：用户从下拉菜单选择另一个动画
- **Then**：新动画从第一帧开始播放，保持播放状态
- **Verification**：`human-judgment`

### AC-2: 模式切换按钮
- **Given**：编辑器处于编辑模式
- **When**：用户点击模式切换按钮
- **Then**：编辑器切换到动画模式，动画开始播放
- **Verification**：`human-judgment`

### AC-3: 编辑模式下动画暂停并恢复初始状态
- **Given**：编辑器处于动画模式且动画正在播放
- **When**：用户点击模式切换按钮切换到编辑模式
- **Then**：动画自动暂停并恢复到初始状态，编辑操作可用
- **Verification**：`human-judgment`

### AC-4: 动画模式下允许编辑关键帧
- **Given**：编辑器处于动画模式
- **When**：用户尝试编辑关键帧
- **Then**：编辑操作允许，关键帧可以被修改
- **Verification**：`human-judgment`

### AC-5: 录制按钮功能
- **Given**：编辑器处于动画模式
- **When**：用户点击录制按钮
- **Then**：系统自动保存用户修改的关键帧
- **Verification**：`human-judgment`

### AC-6: 设置按钮功能
- **Given**：用户调整了骨骼的位置、缩放、旋转等参数
- **When**：用户点击设置按钮
- **Then**：系统主动保存当前参数作为关键帧
- **Verification**：`human-judgment`
