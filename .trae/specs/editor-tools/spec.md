# DragonBones Pro Modern Editor - 编辑工具改进

## 概述
- **摘要**：改进DragonBones Pro Modern Editor的编辑工具功能，包括修复图片点击选择问题，以及实现编辑工具的可视化操作界面。
- **目的**：提高编辑器的可用性，让用户能够通过可视化工具更方便地编辑骨骼和图片。
- **目标用户**：游戏开发者、动画设计师、美术人员。

## 背景
当前编辑器存在两个主要问题：
1. 无法通过点击来选中图片
2. 虽然添加了编辑工具（移动、缩放、旋转），但无法使用，缺少可视化的操作界面

## 功能需求

### 1. 修复图片点击选择
- **FR-1.1**：恢复图片的点击选择功能
- **FR-1.2**：确保点击图片时能够正确选中对应的插槽

### 2. 实现编辑工具的可视化操作
- **FR-2.1**：在选中骨骼或图片时显示对应工具的操作控件
- **FR-2.2**：移动工具：显示两个轴向的箭头，支持拖动调整位置
- **FR-2.3**：缩放工具：显示缩放控制点，支持拖动调整大小
- **FR-2.4**：旋转工具：显示旋转控制点，支持拖动调整角度
- **FR-2.5**：在属性面板中添加对应的参数输入框，支持直接输入数值调整

## 非功能需求
- **NFR-1**：操作控件应该响应迅速，不影响用户体验
- **NFR-2**：操作控件的样式应该清晰直观
- **NFR-3**：功能实现应该保持代码的可维护性和可读性

## 约束
- **技术**：基于现有的React + TypeScript + PIXI.js技术栈
- **依赖**：不引入新的外部依赖

## 接受标准

### AC-1: 图片点击选择
- **Given**：编辑器中加载了带有图片的项目
- **When**：用户点击图片
- **Then**：对应的插槽应该被选中
- **Verification**：`human-judgment`

### AC-2: 移动工具操作
- **Given**：用户选择了移动工具并选中了骨骼或图片
- **When**：用户拖动移动控件
- **Then**：骨骼或图片的位置应该相应调整
- **Verification**：`human-judgment`

### AC-3: 缩放工具操作
- **Given**：用户选择了缩放工具并选中了骨骼或图片
- **When**：用户拖动缩放控件
- **Then**：骨骼或图片的大小应该相应调整
- **Verification**：`human-judgment`

### AC-4: 旋转工具操作
- **Given**：用户选择了旋转工具并选中了骨骼或图片
- **When**：用户拖动旋转控件
- **Then**：骨骼或图片的旋转角度应该相应调整
- **Verification**：`human-judgment`

### AC-5: 参数输入调整
- **Given**：用户选中了骨骼或图片
- **When**：用户在属性面板中输入参数值
- **Then**：骨骼或图片的属性应该相应调整
- **Verification**：`human-judgment`

## 实施计划
1. 修复CanvasRenderer.tsx中的图片点击选择功能
2. 在CanvasRenderer.tsx中添加编辑工具的可视化操作控件
3. 实现移动、缩放、旋转工具的交互逻辑
4. 在属性面板中添加对应的参数输入框
5. 测试所有功能是否正常工作
